# Meraki Concepts & Decor - Website

Simple, responsive, single-page website code for **Meraki Concepts & Decor (Pune)**.

## Files
- `index.html` - main website content.
- `styles.css` - layout, colors, and responsive styles.
- `script.js` - mobile menu + WhatsApp quick inquiry button.

## Deploy on GitHub Pages
1. Push these files to a GitHub repository.
2. In repository settings, open **Pages**.
3. Set source to the main branch (root).
4. Save and wait for the deployment URL.

## Add your real photos/logo
Create an `assets/` folder and add:
- `logo.svg`
- `work-1.svg`
- `work-2.svg`
- `work-3.svg`

Then replace placeholder filenames in `index.html` if needed.
